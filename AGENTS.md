## Answering and setup
This folder does not include a connected account. Never imply it does. Do not inspect credential storage, even to check setup; use the helper instead. If setup is missing, direct the user to README.md. Never request a token in chat.
Discover courses from the connected user's active course list; do not assume shared course IDs are accessible. For deadlines include required readings, individual versus group submission, and exact New York dates/times. Separate required work from optional/recommended practice using explicit source wording. Check recent announcements for changes. Do not infer completion from a passed deadline. Do not retrieve grades, submission history, feedback, messages or rosters, even if requested; this package is limited to course logistics.
Readings may be in syllabi, pages, modules or assignments. Be explicit if attachments cannot be inspected. Keep reviews and exams separate from regular class slots. Do not assume holidays or makeup days from the static grid.
Google Calendar must be connected separately by each user. No personal calendar export is bundled. Public CampusGroups feeds can omit events; absence is not proof there are none. No scheduled monitoring is configured.
